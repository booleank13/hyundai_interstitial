HYUNDAI LOGO PLACEMENT
======================

Please save the Hyundai logo to this directory as:
  hyundai-logo.png

Recommended specifications:
- Format: PNG (with transparent background)
- Dimensions: 400x200px or similar aspect ratio
- File size: < 100KB for optimal loading

The logo image you provided should be saved here to complete the project setup.

Current expected path: assets/images/hyundai-logo.png

If you need to use a different filename, update the src attribute in index.html:
  <img src="assets/images/hyundai-logo.png" alt="Hyundai Logo" class="logo">
